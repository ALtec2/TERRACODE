# TERRACODE
This is a terminal base chess engine. It was built in sublime. 
However that being said I don't think it works since testing was limited to debugging. This does not include logic bugs.

How to use
There is a textfile called Chessboard Uppercase is white lowercase is black. All of the pieces are documented with the first letter of the piece except for knight which starts with n because the king starts with k
